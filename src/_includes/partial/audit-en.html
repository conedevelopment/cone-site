Laravel audit

For a custom application, a regular audit can be an essential task. We help you fully review your Laravel application, whether you are switching developers or just preparing for what comes next.

What can you expect from the Laravel audit?

  • We check how up to date Laravel and its server environment are.
  • We review the dependencies and estimate which ones could likely have been replaced with a simple custom solution.
  • Based on PSR and the Laravel coding guidelines, we check how closely the code follows them or where it deviates from them.
  • We examine the application's architecture and look for points where we would suggest a different structure, other solutions or simply a refactor.
  • We also take a quick look at the front-end and UI code and make suggestions for missing or problematic areas.

WordPress audit

WordPress is a huge system. You can build a simple portfolio site with it or a store with 1000+ products. Auditing these sites is often not easy. When it comes to code quality, the large ecosystem is often a disadvantage.

What can you expect from the WordPress audit?

  • We look at the WordPress instance: the number of plugins and the state of the system. In the long run, it's usually true that the fewer dependencies, the more manageable the system.
  • We examine the theme in use and its dependencies.
  • We make general UI and UX suggestions.
  • We measure how the site performs. Performance is fundamental for a website, and we point out where it falls short.
  • With WordPress, updates are key. An up-to-date system is a secure system. The site (its theme or one of its plugins) may well be stuck on an older version that takes a lot of work to move off. We point this out too.
